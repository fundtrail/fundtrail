# Guest speaker stipend

A $500 stipend paid to one guest speaker, posted to 56712 Participant Support-Stipends (L-7101).

The expected end state is Needs a human, and it stays there:

- The agent flags the charge, because speakers generally aren't participants. The key expects that flag as an `unsure` answer to the `flag` question.
- An honorarium isn't participant support, so the agent's budget line disagrees with the ledger account.
- Money leaving participant support needs NSF's approval. That item goes on the checklist, and it's missing.
- The agent's swap of "participant list" for "honorarium letter" waits for the accountant. Accepting it doesn't make the charge complete.

The second bucket in the key, 90 days after posting, checks that the charge is still Needs a human with nothing new on file.

**Unverified:** which NSF budget line an honorarium belongs on. The key leaves the charge's budget line out, so the eval doesn't score it.

These rulings are provisional, from the build's coordinator, and not yet in the docs.
