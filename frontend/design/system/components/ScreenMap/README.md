# ScreenMap

A picture of every designed screen, in the order the accountant meets them, with the click that leads from one to the next. Six stages: get in, the workspace, adding a grant, working the grant, closing out, and the screens not designed yet (Charges, Evidence and Grant terms, which the sidebar already links to).

**Built from the other cards.** The thumbnails are screenshots of the SignIn, Workspace, WorkspaceMenu, AddGrant, Demo, Closeout and EvidenceReport cards, taken in the states their hash params open. Rebuild the map whenever one of those screens changes, so the thumbnails don't go stale.

**Not a live prototype.** Each screen is its own card; the map shows how they join. The arrows name the real control, word for word, so the map doubles as a checklist when the screens are built.
